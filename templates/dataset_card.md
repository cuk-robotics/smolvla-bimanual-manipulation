# SO-101 bimanual beverage trajectories v1

이 파일은 데이터 카드 양식입니다. 아래 미확인 항목을 실제 기록으로 채운 뒤 게시합니다.

## 작업과 장치

중앙의 고정 사발에 왼팔로 가루를 붓고 통을 복귀시킨 뒤, 오른팔로 플라스틱 비커의 물 100 mL를 붓고 비커를 복귀시키고,
왼팔로 유리컵의 머들러를 집어 젓고 유리컵에 반납하는 작업.
SO-101 양팔 follower/leader, left_wrist/right_wrist/top 카메라 3개.

기본 Hub 이름: `lmsforAI/so101_bimanual_beverage_trajectories_v1_<수집 시각>`.
`v1`은 이 이름으로 시작하는 수집 시리즈의 버전이며 LeRobot 파일 형식 버전과는 별개입니다.
이 템플릿은 실행기가 자동 업로드하지 않습니다. 실제 수집 정보를 확인한 뒤 해당 저장소의 데이터 카드에 반영합니다.

## 형식 및 환경

LeRobot이 생성한 데이터·메타데이터·영상 구조를 그대로 보관합니다.
수집 환경 버전, 장치 구성, 실제 영상 규격을 기록합니다.

## 사용권과 한계

데이터 라이선스: 미정. 프로젝트 코드의 MIT 라이선스를 데이터에 자동 적용하지 않습니다.
설치된 LeRobot 0.6.1의 자동 업로드 데이터 카드는 기본 `apache-2.0`으로 생성됩니다. 실제 데이터 사용권 결정과 일치하는지 확인하고 이 양식에 반영합니다.
실제 태스크 성능, 분할 정책, 편향과 제한 조건: 확인 필요.
