# 개선형 그리퍼 개발

좌·우 각 1개, 총 2개를 개발합니다. 형상과 성능은 아직 확정하지 않았습니다.

향후 기록할 항목:
- CAD 원본·배포 형식, 설계 revision, 제작 조건 및 BOM.
- SO-101 장착 치수, 구동 방식, 질량, 개구 폭과 관절/그리퍼 상태 표현.
- 카메라 장착 위치, 시야 가림, 케이블 간섭.
- 대상 컵·병의 형상/재질별 파지 시험, 미끄러짐·변형·낙하 결과.
- 사용권과 출처: 외부 CAD 및 부품 문서는 원저작자의 조건을 별도로 확인.

현재 CAD, 치수, 하중 등급 및 시험 결과는 제공되지 않습니다.
