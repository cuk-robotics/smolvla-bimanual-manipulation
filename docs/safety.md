# 실물 시험 전 확인 사항

현재 코드는 장치에 연결하지 않습니다. JSON의 dry-run 플래그와 오프라인 검사는
향후 제어 코드의 비상 정지·충돌 방지 기능을 대신하지 않습니다.

실물 연결 기능을 추가하기 전에 다음을 구현·검증합니다.
- 좌·우 포트와 ID 구분, 각 팔·그리퍼 보정 및 단위 확인.
- 기계적 고정, 작업 공간·양팔 간 간섭, 케이블 여유 확인.
- 실제 장치 시험에 근거한 속도·관절·그리퍼 한계 설정. 임의의 안전 수치는 사용하지 않음.
- 통신 단절, 오래된 센서 입력, 모델 오류 시 정지 방식과 재시작 절차 검증.
- 사람의 물리적 정지 수단과 감독. 음성인식을 유일한 비상 정지 수단으로 사용하지 않음.
- 빈 용기부터 단계별 시험. 액체 시험은 유출 방지와 전자부품 보호를 확인한 뒤 수행.

프로젝트의 안전 담당자, 정지 장치 사양, 승인 기준과 시험 기록 형식은 확정 필요 사항입니다.
