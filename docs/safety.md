# 실물 실험 주의사항

현재 무카메라 원격조작(`operation`)·연습·기록·추론(`infer`) 명령은 실제 장치에 연결하고 토크를 활성화합니다.
`scripts/check_config.py`, 단위 검사, `--validate-only`만 장치 연결 없는 검사입니다.

추론은 양팔 정책 출력을 사용하므로 한쪽 팔 작업 문장을 지정해도 두 팔의 이동 공간을 확보합니다.
`infer`는 기본 자동 복귀 없이 공식 연결 해제를 수행합니다. `--return-to-initial-position`을 지정하면 종료·Ctrl+C 시 공식 구현이 양팔과 그리퍼를 실행 시작 관절 위치로 복귀시키려 합니다(기본 3초·50 Hz 선형 보간).
이 복귀는 충돌 회피나 물체 반납 경로를 계획하지 않습니다. 복귀 이동 공간을 확보하고 그리퍼 복귀에 따른 파지 물체 낙하 가능성을 고려합니다. Ctrl+C를 즉시 모터 정지로 간주하지 않습니다.
사용자 요청의 `infer --no-target-limit`은 이번 세션의 양팔 상대 목표 차이 제한을 해제합니다. 모델의 큰 목표 변화도 이 제한 없이 전달되며 기존 보정·단위·종료 토크 해제 설정은 유지됩니다.
실행 제한시간은 반복 경계에서 검사하므로 첫 추론이 제한시간을 넘겨도 목표가 전달될 수 있습니다. 시간 설정은 즉시 정지나 안전성을 보장하지 않습니다.
시연 시작 자세·물체 배치와 실제 모터 추론은 별도로 확인합니다. 명령은 [추론 안내](inference.md)를 참고합니다.

공식 원격조작은 리더의 절대 정규화 관절 목표를 사용합니다.
연결 전 각 리더와 팔로워를 같은 낮은 자세에 정렬하고 베이스를 고정합니다.
설정의 `max_relative_target`은 연결 순간의 움직임이나 모든 물리 위험을 방지하는 장치가 아닙니다.
카메라·포트·보정 파일이 해당 실물 장치와 일치하는지 확인합니다.

팔로워의 이동 범위와 그리퍼에서 손·물체를 치우고 손목 케이블 감김을 확인합니다.
이상 움직임 시 중단하고 원인을 확인합니다. 종료 시 토크가 풀려 관절이 중력으로 처질 수 있으므로
물체를 내려놓고 안정된 낮은 자세로 종료합니다. 소프트웨어 종료를 물리적 비상정지로 간주하지 않습니다.

액체 작업에는 전원·전자부품 보호와 누출·낙하 대응이 필요합니다.
현재 코드에 별도의 충돌 감지, 하중 감지, 정식 안전 제어 기능은 구현되지 않았습니다.
실물 시험 기록·성능 평가와 구조 정리는 별개입니다.
