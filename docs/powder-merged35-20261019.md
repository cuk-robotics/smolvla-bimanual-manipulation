## 병합 방법과 검증

- 설치된 공식 `lerobot.datasets.aggregate.aggregate_datasets`를 사용했다. 원본별 데이터·영상 파일을 별도 유지하는 옵션으로 영상 재인코딩 없이 복사하고, 전역 프레임/에피소드 번호와 파일 참조를 갱신했다.
- 종류별 작업문장·feature schema·관절 순서·영상3개·30 FPS·로봇 종류·v3.0 형식 일치를 확인했다. state/action은 각12차원, 영상은640×480 RGB다. 보정·제어·원본 프레임 값을 변경하지 않았다.
- 원본6개의 Hub payload 전58개 파일을 로컬과 해시 대조했다. 통합본의 모든 프레임 열을 원본과 비교하여 전역 index/episode_index 이외의 값이 동일함을 확인했다. 영상은 원본과 SHA-256이 동일하다.
- 원본에서 물려받은 일부 수치 통계가 실제 프레임과 불일치했다. 커피 action의 일정한 관절 값에서도 표준편차 약0.076831이 기록되는 사례를 확인했다. 통합본의 전역·회차별 **수치 통계만** 전체 프레임으로 재계산했다. float64·모집단 표준편차·정확한 선형 분위수를 사용한다. 원본 통계는 변경하지 않았으며, 영상 통계는 원본 표본 통계의 공식 집계 결과를 유지한다.
