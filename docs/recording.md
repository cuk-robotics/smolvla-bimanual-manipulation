# 음료 제조 시연 수집 기준

작업대 배치, 작업 문장과 시연 채택 기준을 이 문서에서 관리합니다. 실행·종료·이어쓰기는 [운영 안내](operations.md), 저장 완료 수량과 배포 revision은 [데이터셋 목록](datasets.md)을 기준으로 합니다.

2026-10-31 기록 기준으로 가루 3종 각 35개, 물 54개, 젓기 커피 25개·말차라떼 25개가 수집·병합되었습니다. 아래 수량은 해당 수집의 구성과 새 수집 시 재현 기준이며, 정책 성공을 보장하는 최소 수량이 아닙니다. 젓기 아이스티는 이번 수집에서 제외했습니다.

<a id="workspace"></a>
## 작업대와 단계 연결

- 손목 2개와 전체 시야 1개를 유지합니다. 영상은 설정상 640×480·30 FPS이며 센서 실측 FPS와 구분합니다.
- 중앙 컵, 양팔 베이스, 카메라, 머들러 거치 위치를 고정합니다. 기존 작업대 바닥 폼보드는 사용자 보고 90×52 cm이며 이동 후 상대 위치·화각·크롭을 재현합니다.
- 가루통 3개를 항상 장면에 두고 선택한 통만 작은 범위에서 이동합니다. 다른 통을 옮겨야 파지할 수 있으면 기본 간격·이동 범위를 조정합니다. 가루통 출구는 미리 열어 두며 뚜껑 열기는 수집 동작에 포함하지 않습니다.
- 비커 방향·초기 수위, 컵의 가루/물 양, 비작업 팔의 대기 자세를 맞춥니다. 물·젓기는 앞 단계의 종료 상태를 사람이 재현해 독립 수집할 수 있습니다. 매회 컵 내용물을 초기화합니다.
- 가루는 통 반납·팔 대기, 물은 비커 반납·팔 대기, 젓기는 머들러 반납·팔 대기까지 포함합니다. 종료 자세만으로 작업 성공을 판정하지 않습니다.
- 사진상의 좌우와 하드웨어 `left/right` 이름을 혼동하지 않습니다. 작업 문장에 팔 방향을 넣지 않고 실제 시연을 일관되게 유지합니다. 이름만 보고 관절 순서·영상 키·보정을 뒤집지 않습니다.
- 원격조작으로 동작이 가능해진 것과 학습 후 자율 성공은 별도입니다. 음성 입력, 정책 선택, 단계 완료 판정과 자동 연결은 미구현입니다.

머들러는 파지 지점 아래에 손가락 공간을 확보하고, 들어 올려 세우기·삽입·인출·반납 경로를 확인합니다. 고정 받침의 수평 배치는 시험안이며 실제 설치를 단정하지 않습니다. 깊이·여유 공간을 영상만으로 확인하기 어려운 경우의 허용 범위도 현장에서 결정해야 합니다. 실물 절차는 [안전 안내](safety.md)를 따릅니다.

## 작업 문장과 수집 구성

작업 문장은 공식 `dataset.single_task`로 저장됩니다. 설정 파일에 남아 있는 과거 전체 작업 문장 대신 아래 문장을 `--task`로 지정합니다.

| 작업 | 작업 문장 | 기존 수집 구성 | 재배치 |
| --- | --- | --- | ---: |
| 커피 가루 | `Pour coffee powder from the red-lidded container into the cup.` | 정상 30 + 복구 5 | 20초 |
| 아이스티 가루 | `Pour iced tea powder from the blue-lidded container into the cup.` | 정상 30 + 복구 5 | 20초 |
| 녹차라떼 가루 | `Pour green tea latte powder from the green-lidded container into the cup.` | 정상 30 + 복구 5 | 20초 |
| 물 | `Pour water into the cup.` | 가루 3조건 × 18 | 25초 |
| 젓기 | `Stir the mixture in the cup with the muddler.` | 커피 25 + 말차라떼 25 | **30초** |

한 회차의 상한은 180초, 기록은 명목 30 FPS, 손목 입력 MJPG를 사용했습니다. 재료명·색의 대응은 빨강=커피, 파랑=아이스티, 초록=녹차라떼입니다. 색·자리를 바꾼 조건으로의 일반화는 별도 평가 대상입니다.

## 가루와 물의 위치 배분

대상 통/비커의 기준 중심에 가로·세로 1 cm 간격 3×3 점을 사용했습니다. 각 축 ±1 cm, 중심에서 모서리까지 약 1.4 cm입니다. 도달 범위와 간섭을 먼저 확인합니다.

```text
작업대 뒤쪽
P1  P2  P3
P4  P5  P6
P7  P8  P9
작업자 쪽
```

| 위치 | 가루 정상 회차 | 물: 재료 조건별 회차 |
| --- | --- | --- |
| P5 | 0–5 | 0–1 |
| P1 | 6–8 | 2–3 |
| P2 | 9–11 | 4–5 |
| P3 | 12–14 | 6–7 |
| P4 | 15–17 | 8–9 |
| P6 | 18–20 | 10–11 |
| P7 | 21–23 | 12–13 |
| P8 | 24–26 | 14–15 |
| P9 | 27–29 | 16–17 |

배분은 작업자가 수동으로 지킵니다. 통/비커는 그 회차 시작점으로 반납하고 실패 재녹화도 같은 점에서 수행합니다. 다른 통·컵·거치는 고정합니다. 물은 해당 가루만 담긴 컵에서 시작하며 비커 파지→붓기→반납만 기록합니다. 세 음료의 물 목표량·비커·동작이 같다는 공통 정책 전제는 별도로 확인합니다.

복구 5개는 별도 원본 세션으로 수집했습니다. 가벼운 파지 실패→후퇴·재정렬→재파지→붓기→반납까지 완료한 시연을 채택하며 실패·수정 내용과 시작점을 기록합니다. 장시간 헛잡기, 전도, 사람 손으로 해결, 작업 미완료를 정상 성공으로 분류하지 않습니다. 정상 30개와 통합 35개의 성능 차이는 아직 별도 평가 대상입니다.

## 젓기

두 음료에 같은 컵·머들러·작업 문장을 사용하고 음료별 원본 세션을 구분합니다. 한 에피소드의 범위는 다음과 같습니다.

접근·파지 → 들어 올리기·자세 전환 → 컵 위 정렬 → 삽입 → 교반 → 인출 → 원래 위치에 반납·그리퍼 해제 → 팔 대기.

기존 수집 계획은 원형 교반입니다. 실제 교반 횟수·방향·깊이·궤적의 전수 확인은 완료되지 않았습니다. 손목 회전축과 도구 축이 겹치면 자전만 할 수 있으므로 손목 각도 변화만으로 교반 성공을 판정하지 않습니다. 낙하·전도·흘림 여부, 정한 동작 완료와 혼합 정도를 구분해 검토합니다.

**CMD/PowerShell 공통**, 환경 활성화 후 저장소 루트에서 새 일반 3영상 세션을 수집하는 전체 명령입니다. 실제 모터 구동을 포함하며 자동 업로드는 없습니다.

```text
python scripts/run_robot.py record --repo-id local/stir_coffee --task "Stir the mixture in the cup with the muddler." --episodes 25 --episode-seconds 180 --reset-seconds 30 --fps 30 --wrist-fourcc MJPG
python scripts/run_robot.py record --repo-id local/stir_matcha_latte --task "Stir the mixture in the cup with the muddler." --episodes 25 --episode-seconds 180 --reset-seconds 30 --fps 30 --wrist-fourcc MJPG
```

한 번에 한 명령만 실행합니다. 기존 젓기 수집처럼 원본·마스크를 함께 남기려면 [paired 명령](paired-top-recording.md#record)을 사용합니다. 현재 PC의 정확한 마스크 경로·두 음료 명령은 Git 제외 `docs/local/commands.md`에 보관합니다. 25개 명령 재실행은 새 수집이며, 기존 완료 세션의 이어쓰기가 아닙니다.

## 수집 후 채택·병합

세션·원본 회차·재료 조건·시작점·정상/복구·실패/개입·채택 여부를 기록합니다. 프로그램은 성공을 자동 판정하지 않습니다. 파일 수·영상 로딩과 의미적 작업 성공은 구분합니다.

병합 전 [데이터 계약](data-contract.md)의 스키마·행동 의미·보정·제어 조건·영상 대응을 대조합니다. 원본을 보존하고 공식 병합 기능으로 새 통합본을 만들며 파일을 수동으로 이어 붙이지 않습니다. 원본↔통합 회차 대응을 남기고 raw/masked·원본/통합본을 중복 시연으로 세지 않습니다. 평가 조건·추가 수집 판단은 [평가 계획](evaluation.md)에서 관리합니다.
