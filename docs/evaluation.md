# 데이터 검증과 정책 평가

데이터 저장·병합·배포 검증 결과는 [데이터셋 목록](datasets.md)에 기록합니다. 파일 무결성과 실제 작업 성공은 별도 평가입니다. 현재 문서에 근거가 있는 정량 실물 성공률은 없습니다.

| 대상 | 확인 항목 | 현재 근거의 범위 |
| --- | --- | --- |
| 설정·구조 | 경로·공식 CLI·장치/영상 스키마 | 자동 검사 대상 |
| 원격조작 | 방향·추종·시작/종료 자세 | 사용자 확인과 수집 이력; 체계적 측정은 별도 |
| 데이터 | 회차/프레임 수·해시·파일 참조·영상 로딩 | 가루·물·젓기 통합본별 검증 기록 있음 |
| 동작 품질 | 선택·파지·붓기·삽입·교반·반납·흘림/개입 | 영상 검토와 명시적 채택 기준 필요 |
| 정책 | 분리된 조건의 성공률·완료 시간·실패 유형 | 정량 실물 평가 필요 |

## 평가 설계

1. task별 성공 기준을 고정합니다. 재료 투입량, 머들러 교반 횟수·깊이, 허용 흘림·반납 범위 등 아직 확정되지 않은 수치를 측정 전에 정의합니다.
2. 동일 시연의 프레임을 학습/검증으로 나누지 않습니다. 원본/통합본·raw/masked의 대응을 추적하고 에피소드/실험 조건 단위로 분할합니다. raw/masked 비교에는 같은 분할을 적용합니다.
3. 학습 조건을 고정한 반복 평가에서 단계별 실패와 전체 성공률을 함께 기록합니다. 복구 비교는 첫 파지 성공률, 실제 실패가 발생한 시도 중 복구 성공률, 전체 성공률을 구분합니다.
4. 시작 위치·재료 조건·배경 변화는 각각 구분합니다. 실패 평가를 추가 학습에 사용했다면 별도 최종 평가를 확보합니다.
5. 데이터/모델 revision, 보정 식별 정보, 제어 제한, 환경 버전과 개입·지연·완료 시간을 남깁니다.

자동 완료 판정과 단계 연결은 미구현입니다. 정책 손실·행동 오차·설정 검사·저장 관측 추론 성공을 실물 성공률로 환산하지 않습니다.
