# 평가 및 데이터 검증 계획

2026-10-07 현재 가루 50개 수치 검사, 12개 에피소드 정지 영상 표본, 검증 시연 파지 후보의 오프라인 행동 예측 검사를 수행했습니다. [구체적 결과와 다음 비교 실험](archive/powder-data-improvement.md)을 참고합니다. 아래의 미실행·첫 수집 후 확인 표기는 초기 계획이며, 실물 작업 성공률은 여전히 측정 전입니다.

현재 사용자 확인으로 양팔 방향·손목·그리퍼 추종과 카메라 연결이 확인되었습니다.
작업 성공률, 지연 시간, 학습 정책 성능은 측정하지 않았습니다.

| 단계 | 확인 항목 | 상태 |
| --- | --- | --- |
| 설정·구조 | 경로, 공식 CLI 설정, 오프라인 검사 | 자동 검사 대상 |
| 실물 원격조작 | 방향·가동 범위·시작/종료 동작 | 사용자 확인; 체계적 측정 필요 |
| 데이터 | 에피소드, 영상 누락, state/action, 시간 차이 | 첫 수집 후 확인 |
| 작업 | 완료 시간, 유출·낙하, 개입 횟수, 성공 기준 | 기준 확정 및 측정 예정 |
| 정책 | 학습/검증 분리, unseen 조건, 성공률 | 미실행 |

성공 기준에는 컵 지지, 정해진 재료 투입, 지정한 젓기 완료, 누출·낙하 여부를 포함하는 방안을 검토합니다.
정확한 양·횟수·허용 오차는 아직 정하지 않았습니다.
동일 시연 프레임을 학습·검증에 나누지 않고 에피소드/실험 조건 단위로 분리합니다.
평가 결과에는 데이터 revision, 설정, 보정 식별 정보, 환경 버전을 함께 기록합니다.
