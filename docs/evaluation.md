# 평가 계획

현재 측정 결과는 없습니다. 태스크 확정 후 아래 항목을 시험 전에 정의합니다.

| 지표 | 정의할 내용 |
| --- | --- |
| 태스크 성공률 | 성공 종료 조건, 시도 횟수, 제외 기준과 신뢰 구간 |
| 수행 시간 | 시작·종료 시점, 실패/시간 초과 처리 |
| 파지/이동 실패 | 낙하, 미끄러짐, 충돌, 목표 위치 오차 |
| 음료 태스크 | 유출의 판정 방식, 허용 조건과 측정 방법 |
| 사람 개입 | 개입 횟수, 이유, 자율 성공과 개입 후 성공 구분 |
| 언어 입력 | 인식 실패, 지시 해석 실패, 정규화 전후 텍스트 |

비교 실험은 동일한 시험 조건과 분할을 사용합니다. 용기 종류·위치·조명·명령 표현별 결과를 기록하고,
학습에서 사용하지 않은 조건의 결과를 별도로 보고합니다. 영상·상태·정책 입력의 지연도 기록합니다.
목표 성공률, 평가 에피소드 수, 기한과 달성 성능은 아직 정하지 않았습니다.
