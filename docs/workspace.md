# 음료 제조 작업·수집 최종 정리 — 2026-10-19

이 문서는 현재 대화에서 정리한 작업환경·수집·정책 연결의 기준 문서다. README와 PROJECT_CONTEXT는 이 문서를 요약한다. 이전 날짜의 수집 명령·실험 기록은 당시 조건으로 보존한다.

**문서의 최종 정리와 구현·실물 검증 완료를 구분한다.** 아래 기본 방침을 적용하되 수치로 제안한 초기 실험량과 미확인 조건은 그대로 표시한다. 사용자 제공 사진·설명, 기존 코드·설정과 공개 연구에 근거하며 장치를 실행하지 않았다.

실제 수집용 CMD 명령·회차별 격자는 [음료별 녹화 실행안](recording.md)을 사용한다. 사용자 요청에 따라 가루 재배치20초·물25초, 가루3종×30개·물3조건×18개로 각각 종료 후 공개 Hub 업로드를 요청한다. 새 명령은 팔 방향을 문장에서 생략하고 하드웨어 매핑을 유지한다.

## 1. 목표와 작업 순서

초기 입력은 **커피 / 녹차라떼 / 아이스티** 중 하나다. 해당 키워드로 가루 작업 정책 또는 지시를 선택하고 공통 물·젓기 단계를 순서대로 연결한다. 음성 입력을 사용할 경우 음성→텍스트 처리는 별도 구현 대상이다.

| 단계 | 담당 팔: 사진 기준 | 시작 상태 | 완료 상태 |
| --- | --- | --- | --- |
| 선택 가루 | 오른팔 | 빈 중앙 컵, 가루통 3개, 정해진 팔 자세 | 가루 투입 후 그 회차 시작 위치에 통 반납, 팔 대기 |
| 물 | 왼팔 | 해당 가루가 들어 있는 컵, 가루통 반납 완료 | 물을 붓고 시작 위치에 비커 반납, 팔 대기 |
| 젓기 | 왼팔 | 가루와 물이 들어 있는 컵, 비커 반납 완료, 머들러 받침 | 머들러 파지·세우기·삽입·교반·인출 후 원래 받침에 반납 |

- 이번 사용자 지정: 빨강 뚜껑=커피, 파랑 뚜껑=아이스티, 초록 뚜껑=녹차라떼다. 과거 사진의 빨간 표시가 분홍색에 가깝게 보인다는 관찰과 실제 사용자 색 지정을 구분한다.
- 사진상 좌우와 설정 left_arm/right_arm·손목 영상 키의 대응은 확인 필요다. 이름이나 사진만으로 관절 순서·카메라 키·학습 라벨을 뒤집지 않는다.
- 비작업 팔은 정해진 대기 자세를 유지한다. 대기 중 손목 영상에 보드만 보인다는 이유로 카메라를 제외하지 않는다.
- 정책은 현재 영상·관절 상태 등에 따라 행동을 생성한다. 과거 시연을 선택해 그대로 재생하는 방식이 아니다.
- 재료별 가루 모델 + 공통 물 모델 + 공통 젓기 모델 구성을 우선 검토하되 단일 언어 조건 모델과의 최종 선택은 미확정이다.
- 단계 전환은 투입·반납·그리퍼 이탈·대기 자세 등 완료 조건에 근거한다. 시간 만료나 초기 관절 복귀만으로 성공을 판정하지 않는다. 실패 시 다음 단계 진행을 중단하는 처리가 필요하다.

## 2. 카메라와 이동 가능한 작업환경

- 바닥 폼보드: 사용자 보고 **가로 90 cm × 세로 52 cm**. 테이블 전체나 외곽 가림막 치수가 아니며 두께는 미확인이다.
- 손목 2개 + 전체 시야 1개 구성을 유지한다. 현재 로컬 설정의 저장 영상은 640×480·30 FPS다.
- 후보 사진은 **4번 우선, 3번 차선**이다. 4번은 컵 입구·가루통 윗면과 좌우 작업 영역을 균형 있게 보여준다. 2번은 상단 벽 영역이 크고 5번은 오른쪽 통 외곽 여유가 좁다. 정지 사진 판단이며 동작 중 가림의 우열은 미검증이다.
- 4번의 경사 상부 시점을 기준으로 실제 OBS 영상에서 파지·들기·붓기·반납과 머들러 전체 움직임을 확인한다. 휴대폰 사진과 실제 영상의 화각·크롭은 다를 수 있다. 배경을 줄이려다가 도구 끝을 자르지 않는다.
- 바닥 표면과 베이스·카메라·컵·물체의 상대 위치를 기록해 장소 이동 후 재현한다.
- 방 배경 일부 노출만으로 데이터가 부적합한 것은 아니다. 손목 영상에 반복적으로 들어오는 외곽 방향은 이동식 무광 폼보드 가림막을 검토한다. 필요한 방향만 가리고 로봇·도구·케이블 경로와 전체 시야를 침범하지 않는다.
- 가림막 높이·폭은 전체 동작을 보고 정한다. 흰 표면의 반사·화이트아웃과 용기 경계 식별성을 확인한다. 가림막 추가도 영상 조건 변화이므로 기존 모델의 성능 개선을 자동으로 가정하지 않는다.

## 3. 물체 배치

사진상 왼쪽에 비커·머들러, 중앙에 공유 컵, 오른쪽에 가루통 3개를 둔다. 가루통은 부채꼴로 접근 공간을 확보하되 대각선 배열 자체를 오류로 간주하지 않는다.

- 세 통 모두 놓은 채 각 통에 독립적으로 접근·파지·반납할 수 있어야 한다. 가운데 통 양옆의 열린 손가락·손목 카메라 진입 공간을 확인한다.
- 작은 위치 변화 때문에 다른 통을 매번 옮겨야 한다면 기본 간격을 조정하거나 이동 범위를 줄인다. 도달 범위를 벗어나도록 바깥 통을 밀지 않는다.
- 통별 허용 영역의 모양·크기는 달라도 된다. 가운데 통은 좌우 범위를 줄일 수 있다. 정확한 간격·좌표는 실측 전이다.
- 중앙 컵·받침은 미끄러지지 않게 관리한다. 손잡이가 접근을 방해하는 경우에만 방향을 조정한다. 무늬만으로 교체할 필요는 없다.
- 비커의 파지·주둥이·반납 방향을 일관되게 유지하며 머들러를 세우는 경로와 분리한다.
- 통의 색 표시는 유지한다. 필요하면 파지면을 피한 측면 표시를 검토하되 수집·실행에 동일하게 적용한다.
- 2026-10-19 사용자 확인: 가루통 뚜껑의 절반가량 열리는 부분을 미리 열어 둔 상태로 시연을 시작한다. 로봇의 뚜껑 열기는 작업 순서에 포함하지 않는다. 실제 출구 방향·치수와 개방부 고정 여부는 확인 필요다.

## 4. 가루 수집: 색별 자리 고정, 대상 통만 이동

**색별 자리 교환 없이 선택한 통만 작은 격자로 이동하고 다른 두 통은 기준 위치에 고정한다.** 세 통은 모든 시연에 함께 놓는다. 키워드 선택이 주변 물체 영향을 없애는 것은 아니며 실제 운영도 이 배치 조건을 유지하는 범위의 설계다.

- 목표는 정해진 재료 자리의 작은 위치 오차 대응이다. 색의 자리가 바뀌어도 재료를 찾는 능력은 현재 범위 밖이다.
- 3×3 격자를 기준으로 시작한다. x/y 각각 -1, 0, +1 cm면 대각선 최대 거리는 약 1.4 cm다. 반경 약 2 cm는 각 축 ±1.4 cm 정도다. 각 축 ±2 cm는 반경 약 2.8 cm이므로 구분한다.
- 간격은 초기 제안이며 실제 재배치 오차·도달 범위·간섭으로 정한다. 모든 통에 반경 3 cm를 일률 적용하지 않는다.
- 접근 방향·파지 부위·통 반납 기준을 일관되게 하고 중앙 컵은 비운 상태로 시작한다.

| 초기 실험량 제안 | 중앙점 | 주변 8점 | 합계 |
| --- | --- | --- | --- |
| 커피 가루 | 6회 | 점당 3회 | 30개 |
| 녹차라떼 가루 | 6회 | 점당 3회 | 30개 |
| 아이스티 가루 | 6회 | 점당 3회 | 30개 |
| 가루 전체 | | | 90개 |

한 에피소드는 접근→파지→붓기→통 반납→팔 복귀까지다. 각각 새 시연을 수집한다. **정상30개/종은 초기 실험 예산이며 성공 보장이나 입증된 최솟값이 아니다.** 이 격자 배분을 유지한 정상30개와 별도 수집한 복구 후 성공 약5개/종을 원본으로 보존하고, 검증 후 종류별35개 학습용 통합본을 만든다. 가루총105개·물54개 포함159개이며 30개만 학습한 경우와 비교 평가한다. 복구 회차는 실제 실패가 관찰된 9점 범위의 위치를 기록하고 위 정상 격자 회차표와 별도로 관리한다. 구체적 절차는 [녹화 실행안](recording.md)을 따른다.

나머지 통도 움직이는 과거 30개/20개 분배 제안은 현재 필수 계획에 적용하지 않는다. 9³개 배치를 전수 수집하지 않는다. 색 자리 교환은 후속 확장 과제이며 6배열×3목표×5회=90개도 과거 탐색용 예시에 불과하다.

평가는 학습 격자 사이 위치에서도 실시하고 학습과 분리한다. 종류별 격자 사이 10회부터 점검하는 예시는 정밀한 성공률 추정이 아니다. 선택·파지·붓기·반납 실패를 분리하고 물리적 간섭은 배치를 먼저 고친다. 실패 평가를 학습에 재사용하면 별도의 최종 평가를 확보한다.

## 5. 공통 물 정책: 가루 3종의 시작 상태 포함

물의 목표량·비커·동작이 같다면 세 가루 조건을 공통 물 정책에 균형 있게 포함한다. 한 가루에서 성공했다고 나머지에도 성공한다고 간주하지 않는다. 음료별 물 목표량이 다르면 레시피/목표량 조건 또는 정책 분리를 설계한다.

- 매회 컵을 비우고 필요시 세척·건조한 뒤 해당 재료별로 정한 양의 가루만 넣는다. 이전 물·음료가 남은 상태로 반복하지 않는다.
- 가루 분포의 실제 변동은 포함하되 동일 모양으로 성형할 필요는 없다.
- 가루통은 반납 상태, 가루 담당 팔은 대기 자세로 준비한다. 비커 초기 물 양·방향과 물 담당 팔 시작 자세를 맞춘다.
- 가루 단계를 실제로 수행한 상태를 이어 쓰거나 사람이 재현해도 된다. 컵 속 가루뿐 아니라 통·팔 상태도 맞춘다.
- 통의 실제 반납 위치 변동은 대표 표본으로 분산해 포함한다. 가루통 9점×비커 9점을 전수 조합하지 않는다.
- 물 작업 지시는 동작이 같으면 공통으로 유지하고 재료 종류를 에피소드별 수집 기록에 남겨 재료별 평가를 수행한다.

| 비커에도 9개 시작점을 적용할 때의 초기 실험량 제안 | 시연 수 |
| --- | --- |
| 커피 가루가 든 컵 | 9점×2회 = 18개 |
| 녹차라떼 가루가 든 컵 | 9점×2회 = 18개 |
| 아이스티 가루가 든 컵 | 9점×2회 = 18개 |
| 공통 물 전체 | 54개 |

54개는 확정 수량·성공 보장이 아니다. 비커를 고정 위치로 운영하면 격자를 추가할 필요 없이 세 가루 조건에 초기 약 50~60개를 균형 배분하는 안을 검토한다. 녹화 범위는 비커 접근·파지→물 붓기→비커 반납·팔 복귀다.

## 6. 머들러: 젓가락 받침 위 수평 배치를 우선 시험

현재 우선 시험안은 **작업대에 고정한 젓가락 받침 위에 수평으로 놓고 교반 후 같은 받침에 반납**하는 방식이다. 실제 받침 선정·설치·성공 확인은 아직 수행하지 않았다. 과거 유리컵 반납 계획을 현재 기본안으로 적용하지 않는다.

- 파지 구간 바로 아래는 비워 손가락이 들어가게 한다. 받침과 파지 지점을 분리한다.
- 받침 1개로 흔들리면 2개로 떨어진 지점을 지지한다. 구름을 줄이는 얕고 넓은 U/V자 홈을 검토한다.
- 손가락이 도구를 충분히 감싸도 작업대에 닿지 않을 높이가 필요하다. 정확한 높이는 실물 확인한다.
- 받침을 고정하고 길이 방향 미끄러짐도 확인한다. 좁고 깊은 홈은 반납 정렬을 어렵게 할 수 있다.
- 집은 뒤 도구를 세우는 동작은 남는다. 도구 양 끝과 비커·컵의 간섭을 확인한다.
- 꺼내기→빈 컵 삽입→인출→반납을 원격조작으로 반복해 다음 시작 자세가 유지되는지 확인한 뒤 수집한다. 이는 배치 점검이며 자율 정책 검증과 구분한다.
- 자세 전환이 어렵다면 높이·기울기를 제한하는 경사/수직 거치대를 검토한다. 유리컵에 느슨하게 기대는 방식은 방향·높이 변동이 있어 현재 우선안으로 삼지 않는다. RGB만으로 반드시 실패한다는 뜻은 아니다.

도구 길이축과 손목 회전축이 겹치면 자전만 할 수 있다. 축에서 떨어진 끝은 원호를 그리지만 원하는 교반 경로인지 확인해야 한다. 파지 위치·삽입 깊이·컵 벽/바닥 접촉을 확인하고 필요하면 작은 손끝 이동을 포함한다. 손목 회전 명령만으로 혼합 성공이나 연속회전 가능성을 인정하지 않는다.

공통 젓기 정책에는 세 재료의 가루+물 상태와 비커 반납 후 상태를 포함하는 방향이다. 교반 횟수·시간·성공 기준·수집량은 미정이며 물 정책의 54개를 자동 적용하지 않는다.

## 7. 현재 구현과의 차이

- scripts/run_robot.py → src/cuk_robotics/teleoperation/cli.py → 설치된 공식 LeRobot 위임 구조를 유지한다.
- configs/recording/beverage.json에는 과거 전체 작업 문장과 유리컵 머들러 파지·반납 조건이 남아 있다.
- scripts/windows/infer_beverage.bat는 기존 모델과 powder/water를 선택한다. 음료 키워드 3종·젓기·자동 단계 연결 실행기가 아니다.
- SUBTASK_RECORD_GUIDE.md의 50개씩 총 150개는 과거 가루/물/젓기 계획이다. 현재 가루 3종의 초기 수집 90개와 혼동하지 않는다.
- 새 물체·받침·배치와 과거 데이터/모델의 호환성은 미검증이다. 기존 데이터를 폐기하거나 조건이 다른 데이터를 검증 없이 병합하지 않는다.
- 사진상 좌우 확인 전 명령의 left/right나 하드웨어 매핑을 임의 교체하지 않는다.
- 음성 통합·키워드 라우팅·재료별 정책 선택·새 젓기 학습·자동 완료 판정·연쇄 실행·정량 평가는 이번 문서 정리로 구현 완료되지 않는다.
- 코드·로컬 장치 설정·보정·데이터·모델은 변경하지 않았다. 자동 Hub 업로드 기본값은 비활성 상태를 유지한다.

## 8. 확인이 필요한 항목

1. 사진상 좌우와 설정·손목 영상의 대응. 색·재료 대응은 이번 사용자 지시로 확인했다.
2. 실제 top 시야·전체 궤적 가시성·이동 후 상대 배치 재현·폼보드 두께.
3. 통별 허용 이동 범위·접근 공간·컵/베이스 고정·열린 출구 방향과 치수·개방부 고정 여부·붓기 시작 자세와 성공 궤적.
4. 음료별 가루 양·물 목표량·비커 초기 물 양·비커 위치 변화 필요성.
5. 머들러 받침 높이·홈·개수·파지 지점·반납 재현성·교반 궤적과 성공 기준.
6. 단계별/전체 성공률·완료 판정·최종 데이터 수·모델 구성.

## 9. 연구 근거와 해석 범위

- [Akinola 외, ICRA 2020](https://arxiv.org/abs/2002.09107): 다중 시점이 가림·상대 위치 추정 문제를 보완. 후보 4번의 최적성을 입증하지 않는다.
- [Xie 외, 환경 변화와 일반화](https://www.robot-learning.ml/2023/files/paper22.pdf): 작업대 표면·카메라 자세 변화 영향을 분리 평가. 환경 재현의 참고이며 현재 프로젝트 성공률 근거는 아니다.
- [SmolVLA §4.1](https://arxiv.org/html/2506.01844v1): 시작 위치 5개×10개 시연 및 색 분류의 배치 교환 사례. 현재 가루30개/종·물총54개 계획의 충분성을 직접 입증하지 않는다.
- [SayCan](https://say-can.github.io/): 상위 지시와 하위 기술 연결의 참고. 고정 레시피에 LLM을 반드시 도입해야 한다는 뜻은 아니다.
- [Shao 외, ICRA 2020](https://arxiv.org/abs/1911.00969): 고정구로 조작 불확실성을 줄이는 연구. 현재 머들러·젓가락 받침 조합의 성공을 직접 검증하지 않는다.
