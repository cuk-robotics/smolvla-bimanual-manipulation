# 데이터 계약 초안

프로젝트 내부 표준을 먼저 확정하고 선택한 LeRobot 버전으로 변환합니다.
이 문서는 upstream 스키마를 대체하지 않습니다.

- 카메라 이름: `left_wrist`, `right_wrist`, `top`; 실제 위치와 일치하는 고정 ID를 사용.
- 지시: 원문 ASR 결과와 정책에 사용한 정규화 문장을 구분. 지시 변경 시점 기록.
- 상태/행동: 좌→우 순서. 각 관절과 그리퍼의 feature name, 단위, 값 범위, 정규화 방식 기록.
- 개선형 그리퍼가 상태·행동 차원을 변경하는지 확인 후 차원 확정. 현재 특정 차원을 가정하지 않음.
- 시간: 시계 기준, 센서 timestamp, 정책 입력 시점, 실제 행동 적용 시점 기록.
- 동기화: 허용 skew/지연 수치 미정. 누락·오래된 프레임은 검출 후 거부하는 방향으로 구현.
- 이미지: RGB, 크기·FPS·전처리·압축 조건을 기록하고 학습/추론에서 일치시킴.
- 에피소드: task ID, 장치/그리퍼 revision, 캘리브레이션 식별자, 성공·실패·사람 개입 기록.
- 분할: 동일 에피소드 프레임이 학습/평가에 섞이지 않도록 에피소드 단위 이상으로 분리.
- 통계: 정규화 통계는 학습 분할에서 계산. 평가 데이터로 학습 통계를 갱신하지 않음.

데이터 원본은 Git 외부에 보관합니다. 카메라에 포함된 사람·화면·음성과 데이터 사용권을 검토하고,
게시 전 데이터 카드와 라이선스를 작성합니다. 원시 음성 보관은 기본 비활성화입니다.
