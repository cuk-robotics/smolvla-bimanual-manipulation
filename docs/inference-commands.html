02 / 작업 선택 및 명령 복사

각 명령에 폴더 이동·환경 설정 포함

실행 조건과 워밍업

  • 실행 명령: CUDA · 최대 100초 · 상대 목표 차이 제한 유지 · 자동 복귀 없음 · 기록/업로드 없음.
  • 모델 로딩 → 워밍업 2회 → 카메라·모터 연결 → 실행 타이머 시작. 워밍업 행동은 폐기됩니다.
  • 워밍업 중 Rerun은 빈 화면입니다. 연결 후 첫 추론이 끝나야 영상이 표시됩니다. 실행 중 동기 추론 지연은 남을 수 있습니다.
  • 베이스와 이동 공간을 확보합니다. Ctrl+C 종료는 물리적 비상정지가 아니며, 토크 해제 후 팔이 처질 수 있습니다.
  • 물 작업은 세 음료 모두 같은 문장을 사용합니다. 젓기·완료 판정·자동 단계 전환은 포함되지 않습니다.
