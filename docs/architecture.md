# 아키텍처 및 모듈 경계

현재 각 패키지는 역할만 선언한 자리표시자입니다. 다음 계층은 구현 계획입니다.

| 모듈 | 프로젝트 책임 | upstream과의 경계 |
| --- | --- | --- |
| `robot` | 좌·우 팔 구성, 그리퍼 매핑, 실행 전 검증 | LeRobot 장치 인터페이스 활용 |
| `cameras` | 세 시점 식별, 보정, 시간 정렬 | 카메라 캡처 백엔드 연결 |
| `teleoperation` | 동기화된 양팔 시연, 사람 개입 기록 | 선택한 teleoperator 연결 |
| `speech` | ASR, 지시 검토·정규화, 실패 처리 | ASR 공급자와 정책을 분리 |
| `dataset` | 에피소드 계약, 분할, 품질 검사 | LeRobotDataset 변환 |
| `policies` | 영상 key/차원/단위 매핑, 정책 로딩 | LeRobot의 SmolVLA import/공개 API 활용 |
| `evaluation` | 성공·시간·실패·개입 지표 | 검증된 평가 진입점 연결 |

데이터 수집과 정책 추론은 동일한 관측/행동 계약을 사용합니다.
upstream API 변경은 어댑터에서 처리하며 모델 구현을 복제하지 않습니다.
사용할 upstream 버전의 정확한 import 경로와 기능 지원 여부는 통합 시 확인합니다.

음성 지시는 ASR 결과를 작업 텍스트로 바꾼 후 정책에 전달합니다.
문장으로 임의의 시스템 명령을 실행하지 않습니다. 불명확한 지시는 실행하지 않도록 설계합니다.
정책 출력은 물리 장치 명령으로 바로 전달하지 않고 한계·유효성·정지 상태를 검사하는 제어 계층을 거칩니다.
그 제어 계층과 런타임 안전 기능은 아직 구현되지 않았습니다.
