기본 수신 형식에서 오른손목 FPS 저하가 재현된 이력이 있으므로 기록 시 실제 영상 갱신을 확인합니다.

| --- | --- | --- | --- |

투입량·사발 상태·도구 위치를 매 시연의 시작 상태로 복원합니다.
물 단계의 최신 사용자 조건은 같은 비커에 물을 약 절반 채우며, 작업 문장에는 정량을 명시하지 않는 것입니다.
물 단계는 앞선 가루 투입의 종료 상태에 맞춰 커피가루가 들어간 컵으로 시작하도록 권장합니다. 가루 단계 전체를 매번 재촬영할 필요는 없으며, 사람이 컵·가루·도구·팔을 해당 시작 상태로 준비해도 됩니다.
매 물 시연 후 혼합물을 비우고 필요하면 컵을 씻어 가루 상태를 복원하며, 비커도 약 절반 수준으로 다시 채웁니다. 이전 시연의 물을 계속 누적하지 않습니다. 가루량·컵 위치·비커 위치·팔 시작 자세는 가능한 한 일정하게 유지합니다.
현재 재배치 25초가 컵 정리·가루 재투입·비커 재충전에 부족하면 --reset-seconds를 늘립니다. 물 단계는 가루 투입 동작을 함께 기록하지 않고 준비된 상태에서 시작합니다.
가루 종류별 배분, 가루 목표량, 젓기 횟수·시간은 추가 결정이 필요합니다.
한 단계에서 사용하지 않는 팔도 양팔 관측·행동에 포함됩니다.
180초는 에피소드 최대 시간이며 단계의 목표 소요 시간이 아닙니다.
시연이 끝나면 오른쪽 방향키로 종료하고 설정된 재배치 구간(물 25초, 아래 가루·젓기 예시 30초)에서 다음 시연을 준비합니다.
재배치가 완료된 경우 오른쪽 방향키로 다음 시연을 시작할 수 있습니다.
잘못된 시연을 다시 기록하려면 왼쪽 방향키를 사용합니다.

## 마지막 젓기 단계의 준비와 배치

사용자는 앞선 물 단계에서 가루가 들어간 컵에 물을 부었다고 설명했습니다. 젓기는 그 종료 상태에 맞춰 가루와 물이 들어간 컵에서 시작합니다. 앞선 가루·물 동작을 다시 기록할 필요는 없으며 사람이 시작 상태를 준비해도 됩니다.

- 2026-10-07 사용자 요청으로 머들러의 시작 위치를 거치 유리컵 안에서 책상 위로 변경합니다. 중앙 혼합용 컵과 책상 위 머들러의 위치·방향을 우선 고정합니다. 사용자는 시작 위치만 변경했으므로 시연 종료의 유리컵 반납은 유지합니다. 반납용 유리컵도 일정한 위치에 둡니다.
- 머들러가 책상에 밀착되어 있으면 그리퍼 손가락이 바닥에 닿거나 머들러를 밀 수 있습니다. 실제 파지 구간에서 손가락과 책상 사이의 여유, 굴러감·미끄러짐, 카메라 식별성을 확인합니다. 필요하면 파지 구간을 비워 두는 낮은 받침이나 홈으로 위치를 지지하고 수집·추론에 같은 배치를 사용합니다. 책상 파지가 유리컵 인출보다 쉬운지는 실물 확인 전입니다.
- 가루통·비커는 앞선 단계에서 실제로 내려놓았던 영역 안에서 위치·방향을 바꾸는 것을 권장합니다. 책상 전체의 임의 위치로 넓히지 않고, 머들러 파지·이동·삽입·반납 경로를 막지 않는 배치를 사용합니다. 정확한 영역·편차는 아직 측정하지 않았습니다.
- 소수의 대표 배치를 정해 각각 반복 수집할 수 있습니다. 예를 들어 5개 배치×10회로 50개를 구성하되 이는 수집 설계 예시이며 본 교반 작업에 검증된 최적 배분은 아닙니다. 변형마다 충분한 시연을 확보하라는 [공식 SmolVLA 안내](https://huggingface.co/docs/lerobot/v0.6.1/smolvla)를 참고한 권고입니다.
- 양팔은 이전 물 단계가 끝난 대기 자세와 대응하는 시작 자세를 사용하며, 각 리더·팔로워를 정렬합니다. 물 단계에서 사용한 오른팔도 양팔 관측·행동에 포함됩니다.
- 사용자 추가 조건: 머들러는 책상 위에 수평으로 놓여 있으므로 파지 후 도구 축을 약 90° 기울여 수직으로 세운 다음 컵에 넣어야 합니다. 여기서 90°는 도구 방향의 변화이며 특정 모터의 명령 각도 90°를 뜻하지 않습니다. 필요한 관절 조합·회전 방향은 파지 자세와 실물 기구에 따라 확인합니다.
- 권장 순서는 왼팔로 수평 머들러 파지 → 책상에서 들어 올리기 → 책상·컵·주변 물체와 간섭 없는 공간에서 머들러를 수직으로 세우기 → 수직 자세로 컵 위에 정렬 → 천천히 삽입·젓기 → 컵 테두리를 벗어나도록 인출 → 기존 유리컵 반납 → 그리퍼 해제 → 팔 대기입니다. 초기 연습에서는 들어 올리기·자세 전환·컵 이동을 구분하여 같은 궤적으로 반복하는 것을 권장하며, 본 장치에서 검증된 최적 궤적은 아닙니다.
- 회전 여유는 그리퍼 높이뿐 아니라 머들러 양 끝이 회전하며 지나가는 전체 공간으로 판단합니다. 잡은 위치·도구 길이·회전 방향에 따라 필요한 높이가 달라지므로 고정 높이를 임의로 정하지 않습니다. 세운 뒤 교반 끝이 아래로 향하고 삽입에 필요한 길이가 그리퍼 아래에 남는 파지 위치를 선택하되 미끄러짐 여부를 확인합니다.
- 왼손목·탑뷰에서 파지부·머들러 방향 변화·컵 입구와 도구 끝의 상대 위치를 확인합니다. 수직 도구를 축 방향으로 보는 시점만 있으면 기울기 판단이 어려울 수 있으므로 다른 시점의 가시성도 확인합니다. 단계 구분을 위해 길게 정지하거나 별도의 과시 동작을 추가하지 않고 필요한 상태 확인 후 부드럽게 진행합니다. 실제 영상의 가림·초점과 자세 전환 성공은 미확인입니다.
- 매 시연 준비 때 사람이 머들러를 책상 위 시작 위치로 다시 옮깁니다. 젓기 방향·횟수 또는 시간은 수집 전에 한 기준으로 정합니다. 아직 확정된 수치는 없습니다.
- 매 시연 후 이미 저은 혼합물을 그대로 반복 사용하면 초기 혼합 상태가 달라집니다. 앞선 물 단계의 종료 상태에 맞춰 가루·물의 양과 혼합 상태를 다시 준비하고, 머들러·물체·팔을 다음 배치로 복원하는 것을 권장합니다. 재배치 30초가 부족하면 시간을 늘립니다.

중앙 컵·머들러 시작 위치·반납 위치의 변형은 추가 수집·평가 범위로 별도 계획합니다. 물 단계부터 자율 실행할 때도 머들러를 책상 위에서 시작하도록 배치를 맞춥니다. 이미 유리컵 시작 조건으로 수집한 젓기 데이터가 있다면 원본 라벨을 보존하고 시작 조건이 다른 시연으로 구분하여 검토합니다. 이번 권고는 이전 단계의 종료 편차를 다음 단계의 시작 상태에 포함하기 위한 것이며, 실제 배치별 교반 성공을 검증한 결과는 아닙니다.

## CMD 명령

현재 PC의 CMD에서 먼저 환경을 준비합니다.

```bat
C:\miniforge3\condabin\conda.bat activate cuk-robotics
cd /d E:\Desktop\smolvla-bimanual-manipulation
```

가루 50개 — 기록 종료 후 공개 업로드:

```bat
python scripts/run_robot.py record --repo-id lmsforAI/so101_bimanual_beverage_powder_v1 --task "With the left arm, pour powder into the fixed central bowl and return the powder container to its starting position." --episodes 50 --episode-seconds 180 --reset-seconds 30 --fps 30 --display-fps 30 --push-to-hub
```

물 50개 — 가루 수집 프로그램과 업로드가 종료된 후 실행. 컵에 물 붓기와 비커 파지를 명시하고, 정량 표기를 제거했습니다. 최신 사용자 요청으로 재배치 시간을 25초로 늘렸으며, 오른팔·비커 복귀·MJPG 조건은 유지합니다:

```bat
python scripts/run_robot.py record --repo-id lmsforAI/so101_bimanual_beverage_water_v1 --task "With the right arm, pick up the beaker, pour water into the fixed central cup, and return the beaker to its starting position." --episodes 50 --episode-seconds 180 --reset-seconds 25 --fps 30 --display-fps 30 --wrist-fourcc MJPG --push-to-hub
```

젓기 50개 — 물 수집 프로그램과 업로드가 종료된 후 실행. 책상 위 머들러를 집고 중앙 컵을 저은 뒤 기존 유리컵에 반납합니다. 손목 MJPG와 기존 젓기 예시의 재배치 30초는 유지합니다:

```bat
python scripts/run_robot.py record --repo-id lmsforAI/so101_bimanual_beverage_stir_v1 --task "With the left arm, pick up the muddler from the tabletop, stir the mixture in the fixed central cup, and return the muddler to the glass cup." --episodes 50 --episode-seconds 180 --reset-seconds 30 --fps 30 --display-fps 30 --wrist-fourcc MJPG --push-to-hub
```

`--push-to-hub`를 제거하면 로컬 기록만 합니다. 비공개 업로드는 `--private`를 추가합니다.
위 기본 이름 뒤에는 실행시각이 자동으로 붙으며 실행마다 별도 Hub 저장소를 사용합니다.
전체 과정 기본 작업 문장으로 기록하지 않도록 단계별 명령의 `--task`를 유지합니다.

## 분할 수집·종료·학습 준비

50개를 반드시 한 번에 기록할 필요는 없습니다. 나누어 수집할 때는 같은 단계 문장·영상/행동 구성을 유지하고 각 실행의 `--episodes`를 이번 수집 개수로 바꿉니다.
매 실행은 새 데이터셋이므로 단계별 저장 에피소드의 합계가 50개가 되도록 기록합니다. 현재 실행기는 resume을 제공하지 않습니다.
완료 시연을 남기고 조기 종료하려면 오른쪽 방향키로 시연을 끝낸 뒤 재배치 구간에서 Esc를 누릅니다.
시연 중 Esc는 미완료 에피소드가 저장될 수 있고 Ctrl+C는 진행 중 시연 저장을 보장하지 않습니다.
종료 시 물체를 내려놓고 팔을 안정된 낮은 자세에 둡니다. 장치 해제와 업로드 완료까지 기다립니다.

수집 후 단계별 실제 저장 개수·성공 여부·작업 문장·영상 누락·state/action 스키마를 확인합니다.
실패·미완료 시연은 구분하여 검토하고, 중간에 바뀐 카메라/보정 조건도 기록합니다.
학습/검증 분리는 원본 에피소드 또는 수집 세션 단위로 계획합니다.
원본을 보존하면 단계별 학습과 공식 병합 후 단일 모델 학습을 모두 선택할 수 있습니다.
병합 시에도 독립 단계 에피소드 150개의 경계를 유지하며 연속 전체 시연 50개로 이어 붙이지 않습니다.
50개는 이번 수집 목표이며 학습 성공을 보장하는 개수는 아닙니다.
구조·병합 조건은 [데이터 계약](../data-contract.md), 최종 학습 방식의 검토안은 [장기 작업 검토](long-horizon-strategy.md)를 참고합니다.
