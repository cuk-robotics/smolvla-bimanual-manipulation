# 가루 파지 실패: 데이터·학습 개선안

검토일: 2026-10-07. 대상은 `Taem22n/matcha-shaker-w6-261007-01`과 가루 통합 데이터 `merged_v1`이다. 원본 데이터·모델·장치 설정은 보존했으며 실제 로봇 구동이나 재학습은 수행하지 않았다.

## 판단

현재 증거로 데이터 수집 전체가 잘못됐다고 판단할 수 없다. 사용자는 재파지·밀림이 있는 시연을 다시 녹화했고, 카메라 위치·각도를 유지했으며 매 시연 뒤 중앙 용기를 비웠다고 확인했다. 표본 영상과 데이터 수치 검사를 추가했다. 우선순위는 **현재 데이터로 충분히 학습했는지와 파지 구간의 행동 예측을 검증한 뒤, 실패 조건에 한정하여 데이터를 보완하는 것**이다.

## 참고 프로젝트에서 가져올 원칙

Matcha Bot은 GR00T N1.5로 가루·물·젓기를 나눠 약 30개씩 수집했고, 가루 지시는 `Pour matcha powder`였다. 시작·종료를 영상으로 구별하도록 설계했으며 배치 32~64와 최소 1회분 학습을 경험적 권고로 설명했다. 이는 SmolVLA의 최적값이나 성공 보장 조건이 아니다. [제작팀 설명](https://www.hackster.io/sigrobotics/matcha-bot-sigrobotics-embodied-ai-hackathon-1st-place-f0e520#toc-data-collection-4)

따라서 `pick up`이 없는 문장 자체를 이번 실패의 원인으로 지목할 근거는 부족하다. 참고팀의 용기 낙하·젓는 중 종료 방식은 정상 반납이 필요한 우리 목표와 다르다. 정상 반납을 유지하면서 컵 내용물과 완료 자세가 보이도록 구성한다. [제작팀의 상태 구별 설명](https://www.hackster.io/sigrobotics/matcha-bot-sigrobotics-embodied-ai-hackathon-1st-place-f0e520)

SmolVLA 공식 문서는 약 50개를 출발점으로 제시하며, 예시에서는 물체 5개 위치마다 10회씩 반복했다. 카메라 고정, 일정한 파지 방식, 조작 대상의 가시성을 우선하고 변화를 한꺼번에 늘리지 않는 원칙을 적용한다. 이 개수는 우리 가루 작업에 검증된 충분조건이 아니다. [SmolVLA v0.6.1](https://huggingface.co/docs/lerobot/v0.6.1/smolvla), [공식 데이터 수집 지침](https://huggingface.co/docs/lerobot/main/il_robots#tips-for-gathering-data)

## 저장된 검증 시연에서의 예측 결과

가루 검증 에피소드 10개에서 자동 후보의 0.5초 전 관측을 선택해 실제 저장 이미지·state·원본 task를 공식 전처리와 SyncInferenceEngine에 입력했다. 각 관측에서 큐를 초기화하고 난수 seed 0/1/2로 행동 50개를 생성했다. 실제 로봇의 상태를 예측대로 갱신하는 rollout이 아니라, 고정 관측에서 생성한 행동 묶음과 대응하는 원본 미래 목표를 비교한 검사다.

10개 후보의 탑뷰를 직접 대조했다. ep27 frame1332는 이미 가루를 붓고 통을 반납한 뒤 빈 그리퍼를 닫는 구간이므로 초기 파지 분석에서 제외했다. 나머지 9개는 통 파지·들기 부근이다. 정지 화면만으로 최초 접촉의 정확한 시점은 확정하지 않는다. 10개 원시 예측은 모두 보존하고, 아래 집계는 9개×3개 seed=27개 예측만 사용했다.

| 원본 목표 대비 평균 절대 오차 | 묶음 첫 행동 | 50번째 행동 |
| --- | --- | --- |
| 왼팔 shoulder_lift | 2.89° | 5.88° |
| 왼팔 wrist_flex | 2.26° | 4.72° |
| 왼팔 wrist_roll | 1.10° | 1.88° |
| 왼팔 gripper | 2.69 | 30.83 |

그리퍼 단위는 RANGE_0_100이며 각도·mm·성공률이 아니다. 50번째 행동의 그리퍼 목표 평균은 원본 30.66, 예측 61.49였고 27개 예측 모두 원본보다 큰 값이었다. 이 표본에서는 모델이 원본보다 그리퍼를 더 열린 상태로 예측하는 경향이 확인됐다. 원본과 같은 관측에서도 미래 파지 행동을 충분히 재현하지 못하는 근거이며, 실제 통 밀림의 단일 원인이나 재학습만으로 해결됨을 입증하지는 않는다. 관절 오차를 손끝 위치 오차로 직접 환산하지 않는다.

이 작은 검사는 검증셋 전체 평가·실물 성공률·영상과 모터의 실제 지연 검사를 대체하지 않는다. 현재 관측을 그대로 유지하는 기준 예측도 원시 결과에 포함했다. 파지 직전 정지 구간에서는 이 기준의 첫 행동 오차가 작을 수 있으므로 첫 행동 하나의 낮은 오차만으로 모델을 평가하지 않는다.

## 개선 순서와 비교 실험

### 1. 기존 시연과 현재 실행 조건의 기준 확정

- 파지 전 통의 위치·회전, 사발 위치, 양팔 초기 자세를 표본 영상과 비교한다. 카메라가 같아도 물체 배치와 팔 초기 자세가 달라질 수 있다.
- `episode_review.csv`에 파지 시작/완료·붓기·반납 완료 프레임, 가림·블러·대기 구간, 배치 종류를 검토 메모로 남긴다. 성공 여부와 영상 품질을 별도 항목으로 기록한다.
- 자료를 자동 삭제하거나 실패로 자동 라벨링하지 않는다. 사용자 성공 보고와 검수자의 영상 확인을 구분한다.
- 초기·종료의 정지 구간이 길어 보이면 프레임 단위로 표시한 뒤 학습 사본의 구성 변경을 검토한다. 속도 조작이나 영상만 잘라내는 편집은 하지 않는다.

### 2. 학습량을 먼저 통제하여 비교

학습 담당자에게 아래 조건의 비교를 요청할 수 있도록 기준을 정리했다.

| 항목 | 비교 기준 |
| --- | --- |
| 데이터와 분리 | 기존 가루·물 80/20 에피소드 분리 유지. 검증 프레임을 학습에 넣지 않음 |
| 지시·카메라·정규화 | 기존 조건 유지하여 학습량의 효과부터 측정 |
| 배치 | 실제 GPU 메모리에 맞춰 선정. 누적과 프로세스 수를 포함한 유효 배치 기록 |
| 학습 노출 | 우선 약 1회분 이상을 비교 지점으로 두고 중간 체크포인트 평가. 1회가 충분하다는 의미는 아님 |
| 계산 | 유효 배치 2라면 약 76,638스텝/회, 16이면 약 9,580스텝/회, 32이면 약 4,790스텝/회 |
| 학습률 | 현재 cosine scheduler의 num_decay_steps=10,000을 확인. 스텝만 늘리지 말고 새 일정과 재개 방식을 명시 |
| 재개 | 전달된 파일에는 optimizer/scheduler 학습 상태가 없음. 모델 가중치에서 추가 학습하는 것과 학습 상태를 완전히 복원하는 resume을 구분 |
| 판정 | 검증 손실·파지 구간 관절 오차·실물 파지/붓기/반납 성공을 함께 비교. 78.6% 행동 요소 허용 비율을 성공률로 사용하지 않음 |

현재 체크포인트를 보존하고 별도 출력으로 비교한다. 여기서는 학습 실행 명령이나 패키지 변경을 적용하지 않았다. 학습 환경의 실제 진입점·메모리·샘플러·학습 상태 파일이 확인되면 실행 설정으로 구체화한다.

### 3. 실제 추론의 파지 구간을 별도로 평가

- 동일한 시작 배치로 소규모 반복 평가를 먼저 수행한다. 예를 들어 10회는 초기 비교안이며 통계적으로 확정된 성공률 표본 수가 아니다.
- 접근, 통을 밀지 않는 파지, 들기, 붓기, 반납을 각각 기록한다. 파지 전에 실패한 시도를 붓기 성능으로 해석하지 않는다.
- 현재 sync 방식은 50개 행동을 소비한 뒤 새 묶음을 계산한다. 목표 30 FPS에서 50개는 약 1.67초이며 실제 지연은 더해질 수 있다. 현재 구간의 영상·실제 state·모델 목표·전송 목표·묶음 생성 시간을 함께 비교해야 피드백 간격과 추종 오차를 구분할 수 있다.
- 실행 행동 수 감소나 RTC는 후속 비교 항목이다. 동기 방식에서 재계산 빈도를 높이면 멈춤이 더 잦아질 수 있으므로 단순히 숫자를 줄이는 처방으로 확정하지 않는다.
- 자동 시작 자세 복귀는 에피소드 종료의 관절 보간이며, 시연의 통 반납을 대신하거나 파지 오차를 교정하지 않는다.

### 4. 부족한 조건만 추가 수집

충분히 학습한 모델도 특정 배치에서 실패할 때 그 위치·회전 조건의 성공 시연을 보완한다. 처음에는 통 위치·방향·파지 높이·접근 방향을 반복 가능하게 고정한다. 그다음 작은 배치 변화를 몇 그룹으로 나누고 그룹마다 반복 수집한다. 5개 조건×10회는 공식 예시를 참고한 설계 후보이며 추가 50개를 즉시 요구하는 뜻이 아니다.

한 번에 정렬 → 통이 손가락 사이에 들어온 뒤 닫기 → 안정적으로 들기 → 붓기 → 정상 반납의 순서를 유지한다. 닫기 전에 통을 밀고 복구한 사례는 깨끗한 성공 시연과 구분한다. 복구 행동을 학습시킬 경우 별도 목적·라벨로 계획한다. 사람이 손으로 통을 밀어 넣는 개입은 자율 파지의 성공 목표로 포함하지 않는다.

손목 초점·장착 각도를 바꾼다면 새로운 수집 세션으로 기록하고 기존 체크포인트의 평가 조건 변화도 명시한다. 언어 표현을 개선하는 실험은 학습과 추론에 같은 새 라벨을 적용한 별도 사본으로 비교하며, 단순 표현 개선 때문에 정상 원본 영상 전체를 재촬영하지 않는다.

## 연구 담당자 관점의 핵심 질문
