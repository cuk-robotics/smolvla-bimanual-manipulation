## 현재 상태와 문제점

새 저장소는 초기 구성 단계입니다. README에 역할·예정 구조·이전 순서·검증 기준을 작성했습니다.
실행 코드를 이전하거나 새 저장소에서 학습·평가·실물 구동을 완료한 상태가 아닙니다.
기존 저장소의 코드·설정·보정과 실행 경로는 유지합니다.

현재 로컬에는 추론 실행기·워밍업 코드·학습 배치 파일 및 다수의 미커밋 변경이 있습니다.
따라서 원격 저장소를 그대로 복제하는 것만으로 현재 로컬 기능이 이전된다고 판단할 수 없습니다.
PROJECT_CONTEXT.md 후반의 초기 상태 표에는 학습·추론이 개발 예정으로 남아 있으나,
상단의 최신 기록과 현재 소스에는 추론 경로가 존재합니다. 코드 존재와 실물 성능 검증은 구분합니다.

## 이전 기준

1. 이전 파일의 출처 commit, 로컬 변경 여부 및 해시를 기록합니다.
2. 통합 CLI의 의존 관계를 확인하고 학습·추론 모듈과 관련 오프라인 검사를 선별 이전합니다.
3. 공식 LeRobot 위임 원칙을 유지하고 제어·보정·관절 정규화를 임의 변경하지 않습니다.
4. state/action 순서·단위·차원, 영상 키·해상도·FPS 및 작업 문장을 실제 메타데이터로 확인합니다.
5. 데이터·모델은 Hugging Face repo_id와 정확한 revision으로 연결합니다.
6. 원본과 병합본의 중복 시연을 추적해 학습·검증·평가 분할 사이의 누수를 방지합니다.
7. 장치 없는 검사, 저장 관측 추론, 별도 승인된 실물 평가 순서로 검증합니다.
8. 이전 완료 후 기능별 관리 저장소를 명확히 하여 같은 기능을 양쪽에서 독립적으로 수정하지 않습니다.

## 기대 효과와 미확정 사항

수집 환경의 변경을 줄이면서 학습·평가 설정과 최종 실행 코드를 한곳에서 관리할 수 있습니다.
이는 운영 방안이며 현재 재현성이나 실물 성공률 개선이 입증됐다는 의미는 아닙니다.
학습 환경, 단일/단계별 정책 구성, 최종 성공 기준과 평가용 시연 분할은 추가 결정이 필요합니다.
